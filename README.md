## ✨ المميزات

### 🗺️ مدينة حديثة فقط + تتبع مباشر على الخريطة
- كل المتاجر والأسواق والمطاعم داخل **مدينة حديثة** (محافظة الأنبار) مع إحداثيات حقيقية على الخريطة
- **خريطة حديثة التفاعلية** (OpenStreetMap + Leaflet) في صفحة التتبع وفي إتمام الطلب
- **تحديد السائق 🛵/🚗 والعميل 🏠 والمتجر 🍽️** على الخريطة مع خط المسار المتقطع بينهما
- **مدة الوصول المتوقعة** («يصل خلال ~X دقيقة») تُحسب من المسافة الفعلية ونوع مركبة السائق
- **تتبع مباشر**: موقع السائق يتحدث كل 4 ثوانٍ ويتحرك بسلاسة على الخريطة، مع نسبة المسافة المقطوعة وشريط تقدم
- تقدم الطلب تلقائياً: بانتظار القبول → تم القبول → قيد التحضير → السائق في الطريق → تم التسليم
- **منتقي الموقع**: العميل ينقر على خريطة حديثة ليحدد موقع منزله بدقة عند الطلب

### 👤 حسابات المستخدمين (البريد أو الهاتف)
- إنشاء حساب **بالبريد الإلكتروني أو رقم الهاتف** + كلمة مرور (تشفير scrypt وجلسات موقعة بكوكيز آمنة httpOnly)
- الحساب يتيح **التصفح والطلب**؛ إتمام الطلب يتطلب حساباً (بوابة تسجيل أنيقة تحفظ السلة)
- ملف شخصي: الاسم، البريد/الهاتف، العنوان + **طلباتي وتتبعها** (الجارية والسابقة) وتسجيل الخروج
- تعبئة تلقائية لبيانات المستلم من الحساب عند إتمام الطلب

### 🛒 واجهة العميل
- **قسم «المطاعم الأكثر رواجاً في حديثة» 🔥** أعلى الصفحة الرئيسية: شريط أفقي متحرك بترتيب المراتب (1، 2، 3...) حسب الرواج والتقييم
- **موشن بسيط وأنيق** (Framer Motion): ظهور تدريجي متتابع للبطاقات، حركة البانر والشرائح، نبض الشارات الحية
- تصفح حسب التصنيف (الكل / مطاعم / متاجر / أسواق) + بحث فوري
- صفحة متجر كاملة: غلاف، تقييم، وقت التوصيل، أجرة، حد أدنى
- منيو بأقسام مع صور وأسعار بالدينار العراقي + سلة ذكية (سلة لكل متجر)
- دفع نقدي أو بالبطاقة، ملاحظات للوكيل، اختيار الحي من أحياء حديثة

### 👨‍💼 لوحة تحكم المدير
- إحصائيات حية (الطلبات، الإيرادات، الوكلاء المتاحون، أحدث الطلبات، الأكثر طلباً)
- **إضافة/تعديل/حذف مطعم أو متجر أو سوق** (مع خط العرض/الطول لخريطة حديثة) — أي متجر جديد يظهر فوراً للعملاء
- إدارة المنيو لكل متجر (أقسام، أسعار، صور، «الأكثر طلباً»)
- **إدارة الوكلاء: سيارة 🚗 أو دراجة 🛵** مع اللوحة والحالة
- إدارة الطلبات: قبول/تحضير/إلغاء وإسناد الوكلاء بنقرة

### 🛵 تطبيق الوكيل (الكابتن)
- اختيار الوكيل، تشغيل/إيقاف الاستقبال، الطلبات المسندة، تحديث التوصيل، سجل التوصيلات

## 🧰 التقنيات
- **Next.js 16 (App Router) + TypeScript** — تطبيق صفحة واحدة متعدد الواجهات
- **Tailwind CSS 4 + shadcn/ui** + Framer Motion للموشن
- **Prisma + SQLite** (نماذج: User، Store، MenuItem، Agent، Order، OrderItem)
- **Leaflet + OpenStreetMap** لخريطة حديثة (بدون مفاتيح API)
- **Zustand** لإدارة حالة السلة والجلسة

## 🚀 التشغيل المحلي
```bash
bun install
bun run db:push      # إنشاء قاعدة البيانات
bun run db:seed      # بيانات مدينة حديثة التجريبية
bun run dev          # http://localhost:3000
```

## 🗺️ محاكاة التتبع
عند إنشاء الطلب يسير تلقائياً: القبول (٨ ثوانٍ) → التحضير (٢٠ ثانية) → إسناد وكيل والانطلاق (٣٥ ثانية) → حركة السائق على الخريطة حتى الوصول. المدير أو الوكيل يمكنه أيضاً تحديث الحالات يدوياً من لوحاتهما.
